# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-03-03

### Added
- Responsive image styling with `max-width: 100%` for proper viewport scaling
- Definition list (`<dl>`, `<dt>`, `<dd>`) styling matching neubrutalism theme
- Images now include neubrutalism borders and shadows
- Definition terms styled with primary color and bold font
- Definition descriptions with left border accent

### Changed
- Images are now block-level elements with proper margins
- Definition lists now have consistent spacing and visual hierarchy

### Fixed
- Large images now scale properly to fit viewport instead of overflowing
- HTML definition list formatting improved with proper indentation

## [0.1.0] - 2026-03-02

### Added
- Initial release of jekyll-theme-neubrutalism
- Bold neubrutalism design with thick borders and hard shadows
- Customizable color system using CSS variables
- Responsive layouts for all screen sizes
- Multiple page layouts (default, page, post, home, docs)
- Space Grotesk and Space Mono font integration
- GitHub Pages compatibility
- Jekyll Feed and SEO Tag plugin support
- Built-in documentation pages
- Example content and demonstration pages

### Features
- Clear, high-contrast visual design
- Pure CSS implementation with no framework dependencies
- Navigation system with hover effects
- Footer with branding
- Code syntax highlighting
- Blockquote styling
- Custom list markers
- Table styling
- Hero section component
- Post list display
- Horizontal rules with bold styling
